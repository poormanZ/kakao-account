# Escape Room 미니게임 제작 기획서

## 1. 게임 개요

### 1.1 제목
**ESCAPE ROOM : PRIME WORLD**

### 1.2 장르
- 웹 기반 방탈출 / 추리 / 퍼즐
- 4인 협동 플레이를 고려한 병렬 퍼즐 구조
- 스토리 중심의 단계형 퍼즐

### 1.3 핵심 콘셉트
플레이어는 갑작스럽게 정체불명의 이세계에 도착한다. 겉보기에는 평범하지만 곳곳의 숫자가 이상하다. 게임을 진행하면서 이 세계가 **소수(PRIME NUMBER)를 기준으로 유지되는 세계**라는 사실을 스스로 발견한다.

그러나 이 세계에서 벗어나기 위해서는 오히려 그 규칙을 따르지 않는 **비소수(Non-Prime)**를 찾아야 한다.

> **이 세계의 규칙을 따르지 않는 존재만이 이 세계를 벗어날 수 있다.**

---

## 2. 전체 진행

```text
이세계 도착
   ↓
노트북 발견
   ↓
PRIME 규칙 발견
   ↓
생일 기록 조사
   ↓
외부인 발견
   ↓
외부인의 다이어리 발견
   ↓
사색석의 존재 확인
   ↓
4개의 병렬 퍼즐 해결
   ↓
저울로 사색석의 가치 확인
   ↓
사색석 2 → 3 → 5 → 7 순서로 금고 해제
   ↓
17 가치의 이세계 화폐 획득
   ↓
버스 승차권 구입
   ↓
시간 + 버스 번호 조사
   ↓
13:20 / 8121 발견
   ↓
이세계 탈출
```

---

## 3. PHASE 0 — 이세계 도착

플레이어는 자신이 어떻게 이곳에 왔는지 기억하지 못한다. 주변에는 익숙한 물건과 낯선 물건이 섞여 있다.

게임 시작 시에는 `PRIME`이라는 개념을 직접 설명하지 않는다. 플레이어가 주변의 숫자를 관찰하며 규칙을 발견하도록 한다.

---

## 4. PHASE 1 — 노트북

방 안에서 작동하는 노트북을 발견한다.

```text
ID       : PRIME
PASSWORD : 67891
```

로그인 성공 후:

```text
ACCESS GRANTED

FIND THE PERSON.

10 / 11
```

노트북은 생일 기록 조사로 연결된다.

> 기존 색상 → 소수 → 문자 추출 퍼즐은 초기 튜토리얼 또는 별도 도입 퍼즐로 활용할 수 있다.

---

## 5. PHASE 2 — 생일 기록

이세계 사람들의 생일 기록이 놓여 있다.

```text
10월 09일 — 1009
10월 11일 — 1011
10월 13일 — 1013
10월 19일 — 1019
10월 21일 — 1021
10월 31일 — 1031
```

숫자를 하나의 수로 보고 소수 여부를 확인한다.

- 1009 → PRIME
- 1011 → NON-PRIME
- 1013 → PRIME
- 1019 → PRIME
- 1021 → PRIME
- 1031 → PRIME

유일하게 규칙에서 벗어나는 숫자는 **1011**이다.

따라서 10월 11일의 인물이 이 세계의 규칙에 맞지 않는 인물임을 추론한다.

### 인물 정보

```text
10월 09일 — 김하나 — HANA
10월 11일 — 이민수 — MINS
10월 13일 — 박준호 — JUNO
10월 19일 — 최서연 — SEON
10월 21일 — 한지우 — JIWU
10월 31일 — 윤태호 — TAEO
```

10월 11일의 **이민수(MINS)**가 이세계의 사람이 아니라는 사실이 밝혀진다.

---

## 6. PHASE 2.5 — 이민수의 다이어리

이민수의 물건에서 오래된 다이어리를 발견한다. 다이어리는 앞에서 발견한 숫자 규칙과 연결될 수 있도록 작성한다.

### 다이어리 핵심 내용

> 나는 이곳의 사람이 아니다.
>
> 처음에는 나도 이곳이 이상하다는 것을 몰랐다. 하지만 이곳의 사람들은 숫자를 너무 당연하게 받아들인다.
>
> 날짜도, 물건도, 길도 모두 같은 규칙을 따른다.
>
> 이곳에서는 **소수가 특별한 숫자가 아니다.** 오히려 소수가 아닌 것이 이상한 것이다.
>
> 그리고 이 세계에는 네 가지 색의 돌이 있다.
>
> 사람들은 그것을 **사색석(四色石)**이라고 부른다.
>
> 붉은 돌, 푸른 돌, 초록 돌, 노란 돌.
>
> 이곳에서는 사색석을 화폐처럼 사용한다.
>
> 네 돌의 가치는 서로 다르며, 그 값 역시 이 세계의 규칙을 따른다.
>
> **2, 3, 5, 7.**
>
> 하지만 어느 색이 어느 숫자를 의미하는지는 기록되어 있지 않다.
>
> **저울이 진실을 알려줄 것이다.**

---

## 7. PHASE 3 — 사색석 4인 병렬 퍼즐

### 7.1 목적
4명의 플레이어가 동시에 서로 다른 장소의 단서를 조사하고 중앙에서 정보를 합친다.

```text
PLAYER A → 단서 A ┐
PLAYER B → 단서 B ├→ 중앙 저울 퍼즐
PLAYER C → 단서 C ┤
PLAYER D → 단서 D ┘
```

### 7.2 사색석

| 색상 | 이름 | 실제 가치 |
|---|---|---:|
| 🔴 붉은색 | 혈석 | 2 |
| 🔵 푸른색 | 청석 | 3 |
| 🟢 초록색 | 녹석 | 5 |
| 🟡 노란색 | 황석 | 7 |

**토큰에는 숫자를 직접 표시하지 않는다.** 플레이어가 퍼즐을 통해 색과 숫자를 연결한다.

---

## 8. 저울 퍼즐 설계

### 8.1 물리 장치
가능하면 실제 양팔저울을 사용한다.

구성:
- 붉은 토큰 1개
- 푸른 토큰 1개
- 초록 토큰 1개
- 노란 토큰 1개
- 숫자가 적힌 추 세트
- 양팔저울
- 단서 카드 4장

### 8.2 기본 규칙

사색석의 가치는 다음 네 숫자 중 하나이다.

```text
2 / 3 / 5 / 7
```

모든 숫자는 서로 다르다.

### 8.3 권장 풀이 구조

각 플레이어의 단서는 직접 정답이 아니라 **무게 관계**를 제공한다.

```text
단서 A
붉은 돌은 푸른 돌보다 가볍다.

단서 B
초록 돌은 푸른 돌보다 무겁다.

단서 C
노란 돌은 초록 돌보다 무겁다.

단서 D
붉은 돌은 네 돌 중 가장 가볍다.
```

이를 조합하면:

```text
붉은 < 푸른 < 초록 < 노란
```

후보 값이 `2, 3, 5, 7`뿐이므로:

```text
붉은 = 2
푸른 = 3
초록 = 5
노란 = 7
```

마지막으로 실제 저울에서 토큰과 해당 숫자의 추를 비교하여 검증한다.

### 8.4 물리적 체감 강화

```text
논리 추론
   ↓
색상별 가치 예상
   ↓
실제 저울 측정
   ↓
정답 확인
```

저울이 균형을 이루면 해당 색상의 가치가 확정된다.

---

## 9. 중앙 사색석 금고

네 개의 토큰을 모두 확보하면 중앙 금고를 열 수 있다.

금고에는 네 개의 색상 슬롯과 다음 문구가 있다.

> **가장 작은 것부터.**

플레이어는 알아낸 값을 기준으로 토큰을:

```text
2 → 3 → 5 → 7
```

순서로 삽입한다.

```text
붉은 → 푸른 → 초록 → 노란
```

올바른 순서로 넣으면 금고가 열린다.

### 금고 보상

금고 안에는 **17 가치의 이세계 화폐**가 있다.

```text
VALUE : 17
```

17 역시 소수이며, 지금까지의 세계관 규칙과 연결된다. 이 화폐는 탈출을 위한 마지막 비용으로 사용한다.

---

## 10. PHASE 4 — 버스와 귀환

17 가치의 화폐를 가지고 버스 정류장으로 이동한다. 정류장에는 버스 시간표와 버스 번호가 적혀 있다.

### 버스 시간표

| 출발 시간 | 합친 숫자 | 버스 번호 | 판정 |
|---|---:|---:|---|
| 08:11 | 811 | 8009 | PRIME |
| 09:07 | 907 | 8017 | PRIME |
| 10:13 | 1013 | 8053 | PRIME |
| 11:17 | 1117 | 8081 | PRIME |
| 12:23 | 1223 | 8111 | PRIME |
| **13:20** | **1320** | **8121** | **NON-PRIME** |
| 14:23 | 1423 | 8167 | PRIME |
| 15:31 | 1531 | 8191 | PRIME |
| 16:27 | 1627 | 8209 | PRIME |
| 17:47 | 1747 | 8233 | PRIME |

시간은 `HHMM`을 하나의 숫자로 취급한다.

```text
13:20 → 1320
```

1320은 짝수이므로 소수가 아니다.

버스 번호 8121은:

```text
8 + 1 + 2 + 1 = 12
```

3으로 나누어떨어지므로 소수가 아니다.

따라서 유일하게 세계의 규칙에서 벗어난 버스는:

```text
13:20
BUS 8121
```

이다.

---

## 11. 최종 승차권

버스 승차권 가격은 **17**이다.

플레이어는 중앙 금고에서 얻은 17 가치의 화폐로 승차권을 구매한다.

```text
BOARDING PASS

BUS : 8121
TIME: 13:20
DESTINATION : HOME
FARE : 17
```

8121번 버스가 자신의 세계로 돌아가는 길이라는 사실을 확정한다.

---

## 12. 엔딩 연출

버스에 탑승하면 전광판에 숫자가 순차적으로 표시된다.

```text
08:11
09:07
10:13
11:17
12:23
...
13:20
```

화면이 깜빡인 후:

```text
SYSTEM CHECK

PRIME RULE : VIOLATED
BUS 8121 : NON-PRIME

DESTINATION : HOME
```

마지막 문장:

> **이 세계의 규칙을 따르지 않는 존재만이 이 세계를 벗어날 수 있다.**

화면이 암전되며 게임이 종료된다.

## 13. 퍼즐 설계 원칙

### 13.1 답을 먼저 보여주지 않는다
`PRIME`, `NON-PRIME`, `2/3/5/7` 등의 핵심 정보는 처음부터 설명하지 않는다. 플레이어가 숫자를 관찰하고 규칙을 발견하게 한다.

### 13.2 모든 퍼즐은 다음 단계의 이유를 가진다

```text
노트북 → 생일 기록
생일 기록 → 이민수
이민수 → 다이어리
다이어리 → 사색석
사색석 → 저울
저울 → 금고
금고 → 17 화폐
17 화폐 → 승차권
승차권 → 버스
버스 → 귀환
```

### 13.3 물리 소품과 웹 UI

실제 방탈출:
- 노트북
- 다이어리
- 생일 기록지
- 컬러 토큰 4개
- 양팔저울
- 숫자 추
- 중앙 금고
- 버스 시간표
- 승차권

웹 버전:
- 노트북 UI
- 기록 조사 화면
- 다이어리 뷰어
- 토큰 인벤토리
- 디지털 저울 인터랙션
- 금고 슬롯
- 버스 시간표
- 승차권 구매 화면
- 엔딩 연출

## 14. 4인 협동 플레이

4명의 플레이어가 각자 다른 장소를 조사한다.

- PLAYER 1 → 붉은 사색석 관련 단서
- PLAYER 2 → 푸른 사색석 관련 단서
- PLAYER 3 → 초록 사색석 관련 단서
- PLAYER 4 → 노란 사색석 관련 단서

각자의 단서는 혼자서는 완전한 정답이 되지 않는다. 네 명이 정보를 공유해야 전체 순서를 완성할 수 있도록 한다.

---

## 15. 보안 및 정답 검증

웹 게임에서는 클라이언트 소스에서 최종 정답을 직접 노출하지 않는다.

```text
Browser
   │
   │ puzzle answer / progress
   ▼
Cloudflare Worker
   │
   │ server-side validation
   ▼
ACCESS GRANTED / ACCESS DENIED
```

최종 정답 및 진행 상태는 서버 측에서 검증한다.

클라이언트 코드에 다음 값을 단순 문자열로 직접 넣지 않는다.

- 최종 탈출 코드
- 서버 검증용 Secret
- 단계별 정답 상태

단, 정상적인 플레이로 추론할 수 있어야 하는 퍼즐 정보는 게임 화면에서 제공한다.

## 18. 디자인 철학

이 게임의 핵심 재미는 단순히 소수 문제를 푸는 것이 아니라, 플레이어가 게임을 진행하면서 세계의 규칙을 발견하고 마지막에 그 규칙을 역으로 이용해 탈출하는 과정이다.

```text
"숫자가 이상하다."
        ↓
"이 숫자들은 소수네?"
        ↓
"1011만 소수가 아니야."
        ↓
"10월 11일 사람이 이상하다."
        ↓
"이 사람도 외부인이었어."
        ↓
"이 세계의 화폐도 소수 규칙을 따르네."
        ↓
"2, 3, 5, 7의 정체를 찾아야 해."
        ↓
"저울로 색깔별 가치를 확인한다."
        ↓
"17을 얻었다."
        ↓
"버스 시간과 번호도 전부 소수야."
        ↓
"그런데 13:20 / 8121만 소수가 아니야."
        ↓
"저 버스가 이 세계의 규칙에서 벗어난 길이다."
        ↓
"집으로 돌아갈 수 있다."
```

최종적으로 **1011이라는 비소수의 사람과 8121이라는 비소수의 버스가 하나의 이야기로 연결**되도록 한다.

> **세계의 규칙에서 벗어난 존재가 곧 탈출구다.**

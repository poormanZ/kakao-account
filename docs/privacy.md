# 개인정보 보관 및 삭제 정책

## 1. 보관 데이터

서비스는 Kakao Login을 통해 내부 계정을 식별하기 위해 다음 최소 정보를 D1에 보관한다.

- 내부 사용자 ID
- Kakao 사용자 식별자
- Kakao에서 제공되는 닉네임 및 프로필 이미지 URL(사용 가능한 경우)
- 서비스 세션 및 만료 시각
- 사용자가 저장한 서비스 설정

Kakao access token과 refresh token은 장기 인증 데이터로 D1에 저장하지 않는다.

## 2. 세션 보관

서비스 세션은 발급 후 최대 30일 동안 유효하다. 만료된 세션은 요청 처리 중 발견되면 즉시 삭제하며, Worker Cron Trigger를 통해 시간당 한 번 만료 세션을 정리한다.

## 3. 계정 삭제

인증된 사용자는 `DELETE /api/account`를 통해 자신의 서비스 계정을 삭제할 수 있다.

삭제 요청에는 다음 JSON 본문이 필요하다.

```json
{"confirmation":"DELETE"}
```

정확한 확인 문자열을 요구하여 실수에 의한 파괴적 요청을 방지한다.

계정 삭제 시 다음 사용자 소유 데이터가 함께 삭제된다.

- `user_settings`의 사용자 설정
- `sessions`의 서비스 세션
- `users`의 내부 계정 및 Kakao 식별자

세 데이터 삭제는 D1 batch 작업으로 하나의 원자적 작업으로 처리한다. 삭제가 완료되면 현재 서비스 세션 쿠키도 즉시 폐기한다.

## 4. Kakao 계정과의 관계

서비스 계정 삭제는 이 서비스의 내부 데이터 삭제를 의미한다. Kakao 계정 자체의 탈퇴나 서비스 연결 해제(unlink)는 별도 절차이며, 서비스 계정 삭제 API가 Kakao 계정을 삭제하지 않는다.

## 5. 향후 확장 데이터

향후 서비스별 데이터가 추가될 경우 각 데이터 모델에 사용자 소유 관계와 삭제 정책을 명시하고, 계정 삭제 시 함께 삭제되도록 설계한다.

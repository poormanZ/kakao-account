# 9Grid 게임 규칙 확정

## 1. 기본 구조

- 3×3 보드에 카드를 배치한다.
- 카드 1장은 `종족 1개 + 직업 1개`를 가진다.
- 현재 종족은 `GOBLIN / ELF / DWARF / DRAGON` 4종이다.
- 현재 직업은 `WARRIOR / TANK / HEALER / MAGE` 4종이다.
- 한 라운드는 최대 9턴이다.
- 몬스터를 9턴 전에 처치하면 즉시 라운드 클리어하고 다음 라운드로 진행한다.
- 9턴 종료 시 몬스터가 살아 있으면 게임 오버다.
- 플레이어 HP가 0이 되면 즉시 게임 오버다.

## 2. 기본 플레이어 스탯

게임 시작 시 플레이어는 다음 4개의 기본 스탯을 가진다.

- 공격력
- 방어력
- 생명력
- 마나

직업 카드를 배치할 때 다음 스탯을 영구적으로 +1 증가시킨다.

| 직업 | 배치 효과 |
|---|---|
| WARRIOR | 공격력 +1 |
| TANK | 방어력 +1 |
| HEALER | 생명력 +1 |
| MAGE | 마나 +1 |

## 3. 턴 진행

1. 후보 카드 3장을 받는다.
2. 기본 리롤 횟수와 고블린 시너지에 따라 원하는 후보를 리롤한다.
3. 후보 1장을 선택한다.
4. 선택한 카드를 보드에 배치하거나 기존 카드와 교체한다.
5. 종족/직업 시너지를 계산한다.
6. 전투를 실행한다.
7. 다음 턴 또는 다음 라운드로 진행한다.

카드 배치는 게임 상태에 따라 선택 사항이며, 배치하지 않아도 현재 보드로 전투할 수 있다.

## 4. 시너지 Base Rule

모든 종족/직업 시너지는 **한 줄 완성**을 기준으로 한다.

- 가로 3칸 또는 세로 3칸을 완성한 경우 판정한다.
- 대각선은 판정하지 않는다.
- 한 라인의 3장이 모두 같은 종족이면 해당 종족 시너지 +1.
- 한 라인의 3장이 모두 같은 직업이면 해당 직업 시너지 +1.
- 같은 라인에서 종족과 직업을 동시에 만족하면 두 시너지가 모두 +1.
- 하나의 카드는 가로와 세로 라인에 동시에 기여할 수 있다.
- 모든 시너지는 **LV0에서 시작**한다.
- 시너지 최대 레벨은 **LV5**다.
- 완성된 라인은 한 번만 시너지 레벨에 반영한다.
- 카드 교체로 라인이 깨지면 현재 보드 기준으로 시너지 레벨을 다시 계산한다.

## 5. 시너지 배율

직업 시너지의 기본 효과 배율은 다음과 같다.

```text
효과 배율 = 시너지 LV + 1
```

| LV | 배율 |
|---:|---:|
| LV0 | ×1 |
| LV1 | ×2 |
| LV2 | ×3 |
| LV3 | ×4 |
| LV4 | ×5 |
| LV5 | ×6 |

초기 밸런스에서는 이 배율을 사용한다. 라운드별 몬스터 HP/공격력과 실제 플레이 데이터를 확인한 후 추후 배율 곡선을 조정한다.

## 6. 직업 시너지

### WARRIOR

```text
피해량 = 공격력 × (전사 시너지 LV + 1)
```

### TANK

```text
시너지 방어력 = 방어력 × (탱커 시너지 LV + 1)
받는 피해 = max(0, 상대 피해 - 시너지 방어력)
```

### HEALER

현재 보드에 배치된 힐러 카드 수를 회복량의 기본값으로 사용한다.

```text
회복량 = 현재 배치된 힐러 수 × (힐러 시너지 LV + 1)
```

회복 후 HP는 최대 생명력을 초과하지 않는다.

### MAGE

현재 마나를 마법 피해량의 기본값으로 사용한다.

```text
마법 피해량 = 마나 × (법사 시너지 LV + 1)
```

법사는 마나를 사용하는 별도의 마법 공격 수단을 담당한다.

## 7. 종족 시너지

### GOBLIN

기본 리롤 횟수에 고블린 시너지 LV만큼 추가 리롤을 제공한다.

```text
추가 리롤 횟수 = 고블린 시너지 LV
```

### ELF

기본 공격 횟수에 엘프 시너지 LV만큼 추가 공격을 제공한다.

```text
추가 공격 횟수 = 엘프 시너지 LV
```

### DWARF

카드 배치 시 해당 직업의 기본 스탯 증가량에 드워프 시너지 LV를 추가한다.

```text
최종 배치 스탯 증가량 = 직업 기본 증가량 + 드워프 시너지 LV
```

예: 전사 카드의 기본 공격력 +1에 드워프 LV3이 적용되면 해당 배치에서 공격력 +4.

드워프 시너지는 카드가 배치되는 시점의 LV를 기준으로 하며 이미 적용된 영구 스탯을 소급 변경하지 않는다.

### DRAGON

게임 클리어 시 드래곤 시너지에 따른 점수 보너스를 적용한다.

```text
드래곤 보너스 점수 = 클리어 라운드 × 드래곤 시너지 LV
```

## 8. 전투 처리 기본 순서

1. 현재 보드의 종족/직업 시너지를 계산한다.
2. 현재 플레이어 기본 스탯을 확인한다.
3. 직업 시너지 효과를 계산한다.
4. 종족 시너지 효과를 적용한다.
5. 엘프 추가 공격 횟수에 따라 공격을 반복한다.
6. 몬스터 HP를 감소시킨다.
7. 몬스터가 생존하면 반격한다.
8. 탱커 방어 효과를 적용한다.
9. 힐러 회복 효과를 적용한다.
10. 플레이어 HP가 0이면 게임 오버, 아니면 다음 턴으로 진행한다.

실제 전투 적용 순서는 구현 시 단위 테스트로 고정한다.

## 9. 라운드

- 각 라운드는 최대 9턴이다.
- 라운드 클리어 후 보드는 유지한다.
- Round 2부터는 기존 카드를 교체하여 빌드를 개선한다.
- 몬스터는 라운드가 올라갈수록 강해진다.

## 10. 점수

드래곤 시너지 보너스를 포함한 최종 점수를 기록한다.

기본 랭킹 우선순위는 최대 클리어 라운드를 사용하며, 기존 타이브레이커 정책을 유지한다.

## 11. MVP 범위

현재 MVP에서는 다음만 사용한다.

- 종족 4종: GOBLIN, ELF, DWARF, DRAGON
- 직업 4종: WARRIOR, TANK, HEALER, MAGE
- 기본 스탯 4종: 공격력, 방어력, 생명력, 마나
- 3×3 보드
- 가로/세로 시너지
- LV0~LV5
- LV+1 배율
- 리롤
- 카드 배치/교체
- 단순 종족/직업 시너지

다음 시스템은 MVP에서 제외한다.

- 카드 생성/토큰
- 묘지/부활
- 카드 복제
- 카드별 복잡한 고유 효과
- 추가 자원
- 복잡한 덱 관리

필요성이 실제 플레이에서 확인된 경우에만 추후 추가한다.

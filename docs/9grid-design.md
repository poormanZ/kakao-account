# 9Grid 카드/시너지 설계 문서

## 1. 문서 목적

9Grid의 기존 `속성 + 직업` 카드 구조를 `종족 + 직업` 구조로 전환하기 위한 설계 기준을 정의한다.

이 문서는 구현 세부사항보다 게임 규칙과 확장 가능한 데이터 모델을 먼저 고정하는 것을 목적으로 한다.

## 2. 핵심 설계 방향

- 카드의 기본 정체성은 `종족(Race) + 직업(Job)`이다.
- 종족은 덱의 핵심 전략과 시너지 방향을 결정한다.
- 직업은 전투 역할과 공통적인 전투 효과를 결정한다.
- 향후 개별 카드 효과를 추가하여 `종족 시너지 + 직업 시너지 + 카드 고유 효과`의 3계층 구조로 확장한다.
- 기존 3×3 보드 구조와 가로/세로 6개 라인 판정은 유지한다.
- 대각선은 MVP 시너지 판정에서 제외한다.
- 하나의 완성된 라인은 종족 시너지와 직업 시너지를 독립적으로 동시에 발동할 수 있다.
- 동일 종족/직업 시너지가 여러 라인에서 발생하면 라인 수에 따라 누적되는 구조를 기본으로 한다.

## 3. 카드 구조

```ts
type Race =
  | "goblin"
  | "merfolk"
  | "undead"
  | "dragon"
  | "giant"
  | "demon"
  | "elf"
  | "dwarf"
  | "machine";

type Job =
  | "warrior"
  | "mage"
  | "rogue"
  | "priest"
  | "warlock"
  | "hunter"
  | "paladin"
  | "druid";

interface Card {
  id: string;
  race: Race;
  job: Job;
}
```

초기 설계는 9종족 × 8직업 = 72개의 조합을 지원할 수 있도록 한다.

## 4. 종족 설계

### 4.1 Goblin

- 핵심 키워드: 저비용, 토큰, 희생, 물량
- 전략: 많은 카드를 빠르게 전개하고 아군 희생을 공격력/효과로 전환한다.
- 주요 시너지: 카드 수와 희생된 아군을 활용하는 공격적 효과
- 권장 직업: Rogue, Hunter
- 주의점: 무한 전개가 실제 무한 루프가 되지 않도록 턴/자원/효과 횟수 제한이 필요하다.

### 4.2 Merfolk

- 핵심 키워드: 동족 수, 버프, 집결
- 전략: 필드 위 동일 종족 수가 많을수록 아군을 강화한다.
- 주요 시너지: 필드의 Merfolk 수에 비례한 공격/방어/회복 계열 강화
- 권장 직업: Hunter, Paladin
- 주의점: 보드 최대 9칸을 기준으로 효과 상한을 명확히 한다.

### 4.3 Undead

- 핵심 키워드: 부활, 묘지, 시체 자원, 죽음 스택
- 전략: 카드가 사라지거나 희생된 뒤 이를 자원으로 재활용하여 후반에 강한 부활 효과를 만든다.
- 주요 시너지: 사망 카드 누적 → 부활/재사용/광역 효과
- 권장 직업: Priest, Warlock
- 주의점: 부활 대상과 횟수를 제한하여 무한 재귀를 방지한다.

### 4.4 Dragon

- 핵심 키워드: 손패, 대형 효과, 광역 공격
- 전략: 손패에 존재하는 Dragon 수를 활용해 강력한 효과를 발동한다.
- 주요 시너지: 손패 Dragon 수에 따른 광역 피해 또는 강력한 스킬 효과
- 권장 직업: Mage, Druid
- 주의점: 손패 기반 효과와 필드 시너지를 구분해 계산한다.

### 4.5 Giant

- 핵심 키워드: 비용 감소, 자원 관리, 대형 카드
- 전략: 손패/HP/자원 등의 조건을 충족할수록 카드 비용 또는 효과 부담을 낮춘다.
- 주요 시너지: 조건부 비용 감소 및 고효율 카드 운용
- 권장 직업: Warrior, Priest
- 주의점: 비용 감소의 최소값과 중첩 횟수를 명확히 한다.

### 4.6 Demon

- 핵심 키워드: 고위험, 고능력치, 자해, 흡혈
- 전략: 자신의 HP나 자원을 희생해 높은 공격력과 강력한 효과를 얻는다.
- 주요 시너지: 자해량/희생 자원에 비례한 공격 강화, 흡혈, 소환
- 권장 직업: Warlock, Warrior
- 주의점: 자해로 인한 즉시 게임 오버와 보상 효과의 순서를 명확히 정의한다.

### 4.7 Elf

- 핵심 키워드: 연계, 주문, 콤보
- 전략: 한 턴에 여러 카드를 연속으로 연결할수록 효과를 증폭한다.
- 주요 시너지: 이번 턴 카드 연계 횟수에 따른 주문/스킬 강화
- 권장 직업: Mage, Rogue
- 주의점: 연계 횟수 초기화 시점을 턴 경계에서 명확히 한다.

### 4.8 Dwarf

- 핵심 키워드: 부품, 융합, 방어구, 장비
- 전략: Dwarf 카드와 부품/장비 효과를 결합해 방어적인 전투력을 높인다.
- 주요 시너지: 장비/부품 누적에 따른 방어력 및 지속 전투력 강화
- 권장 직업: Warrior, Paladin
- 주의점: Machine과의 역할 중복을 피하고 Dwarf는 장비/장착 중심으로 정의한다.

### 4.9 Machine

- 핵심 키워드: 부품 조립, 융합, 기계적 강화, 템포
- 전략: 여러 Machine 부품을 조립하거나 융합하여 단기적인 전투 효율을 크게 높인다.
- 주요 시너지: 부품 조합 및 융합에 따른 공격/방어/효율 증가
- 권장 직업: Paladin, Warrior
- 주의점: Dwarf의 장비 시스템과 구분하여 Machine은 부품 조합/융합 자체를 핵심으로 한다.

## 5. 직업 설계

### Warrior

- 키워드: 방어구, 도발, 분노
- 전략: 피해를 견디며 분노를 쌓고 공격력을 높여 반격한다.
- 권장 종족: Dwarf, Machine, Giant

### Mage

- 키워드: 주문력, 빙결, 비전 비밀
- 전략: 주문 폭발과 상대 턴을 방해하는 비밀/제어 효과를 사용한다.
- 권장 종족: Elf, Dragon

### Rogue

- 키워드: 콤보, 은신, 훔치기
- 전략: 다른 카드가 같은 턴에 먼저 사용되었을 때 추가 효과를 발동해 템포를 확보한다.
- 권장 종족: Goblin, Elf

### Priest

- 키워드: 회복, 영웅 능력, 정신 지배
- 전략: 회복과 능력치 누적으로 장기전을 유리하게 만들고 일부 효과를 공격 효과로 전환한다.
- 권장 종족: Undead, Giant

### Warlock

- 키워드: 드로우, 자해, 악마 소환
- 전략: HP나 덱/손패 자원을 희생해 카드와 강력한 효과를 확보한다.
- 권장 종족: Demon, Giant

### Hunter

- 키워드: 야수, 비밀, 명치 압박
- 전략: 빠른 공격과 상대 영웅 직접 피해로 극단적인 어그로를 구축한다.
- 권장 종족: Goblin, Merfolk

### Paladin

- 키워드: 신성 보호막, 하수인 강화, 모집
- 전략: 보호막과 아군 버프로 안정적인 중속 덱을 구성한다.
- 권장 종족: Dwarf, Merfolk

### Druid

- 키워드: 마나 램프, 선택, 성장
- 전략: 초반 자원을 빠르게 확보하고 상황에 따라 두 가지 효과 중 하나를 선택한다.
- 권장 종족: Dragon, Giant

## 6. 시너지 판정 규칙

보드의 다음 6개 라인을 독립적으로 검사한다.

- 가로 3개
- 세로 3개
- 대각선 제외

완성된 한 라인의 3장이 모두 같은 종족이면 해당 종족 시너지를 1회 발생시킨다.

완성된 한 라인의 3장이 모두 같은 직업이면 해당 직업 시너지를 1회 발생시킨다.

따라서 한 라인이 `같은 종족 + 같은 직업`으로 구성될 경우 두 시너지가 동시에 발동한다.

예:

```text
Goblin/Rogue  Goblin/Hunter  Goblin/Rogue
Goblin/Mage   Elf/Mage       Undead/Priest
Dwarf/Warrior Dwarf/Paladin  Dwarf/Warrior
```

첫 번째 행은 Goblin 종족 시너지를 발생시키지만 직업은 일치하지 않는다.
세 번째 행은 Dwarf 종족 시너지를 발생시키지만 직업은 일치하지 않는다.
두 번째 열은 Hunter/Mage/Priest이므로 직업 시너지가 없다.

## 7. 효과 데이터 모델 방향

구현에서는 종족과 직업을 단순 문자열 분기문으로 계속 확장하지 않고 정의 데이터와 계산 로직을 분리한다.

권장 구조:

```text
RaceDefinition
 ├─ id
 ├─ name
 ├─ description
 ├─ synergy condition
 └─ synergy effect

JobDefinition
 ├─ id
 ├─ name
 ├─ description
 └─ combat effect
```

향후 필요할 경우 다음 계층을 추가한다.

```text
CardDefinition
 ├─ id
 ├─ race
 ├─ job
 ├─ base stats
 └─ unique effect
```

## 8. 자원/효과 확장 원칙

현재 9Grid의 기본 전투 루프를 유지하면서 새로운 종족 효과를 추가한다.

효과를 구현할 때 다음 규칙을 따른다.

1. 효과의 발동 조건을 명시한다.
2. 효과가 적용되는 대상과 범위를 명시한다.
3. 효과의 지속 시간을 명시한다.
4. 동일 효과의 중첩 규칙을 명시한다.
5. HP/자원/손패/묘지 등 상태를 변경하는 효과는 변경 순서를 명시한다.
6. 무한 루프가 가능한 소환/부활/드로우 효과는 횟수 또는 자원 상한을 둔다.
7. UI에서 플레이어가 효과의 원인을 확인할 수 있어야 한다.

## 9. 기존 9Grid 진행 규칙과의 관계

카드 시스템을 변경하더라도 다음 게임 루프는 유지한다.

- 한 턴에 카드 후보 3장을 제시한다.
- 턴당 1회의 부분 리롤을 사용할 수 있다.
- 후보 중 1장을 선택할 수 있다.
- 카드 배치는 선택 사항이다.
- 카드를 선택하지 않거나 배치하지 않아도 기존 보드로 전투를 실행할 수 있다.
- 빈 칸에는 카드를 추가하고, 점유 칸에는 카드를 교체할 수 있다.
- 전투 후 실제 배치된 후보 카드만 자동 리롤한다.
- 라운드는 최대 9턴이다.
- 몬스터가 9턴 이전에 처치되면 즉시 라운드를 클리어한다.
- 플레이어 HP가 0이면 즉시 게임 오버다.
- 9턴 종료 시 몬스터가 살아 있으면 게임 오버다.

## 10. 구현 순서

1. `Element`를 `Race`로 교체한다.
2. 초기 9종족과 8직업 타입을 정의한다.
3. 카드 생성/검증 로직을 Race + Job 기준으로 변경한다.
4. 기존 가로/세로 시너지 계산기를 Race + Job 기준으로 변경한다.
5. 종족/직업 정의 데이터를 별도 구조로 분리한다.
6. 종족/직업별 실제 전투 효과를 단계적으로 구현한다.
7. 관련 단위 테스트를 추가/수정한다.
8. UI의 카드 표기와 시너지 표시를 변경한다.
9. 실제 플레이 밸런싱 및 UX 검증을 수행한다.

## 11. 밸런싱 원칙

- 종족은 덱 구축 방향을 강하게 만들되 단독으로 모든 상황을 해결하지 않도록 한다.
- 직업은 종족과 조합했을 때 시너지가 강화되지만 어떤 종족에서도 기본적인 역할을 수행할 수 있어야 한다.
- 특정 조합이 모든 다른 조합보다 항상 우월하지 않도록 비용/효과/발동 조건을 함께 조정한다.
- 초기 구현에서는 강한 효과보다 규칙의 명확성과 테스트 가능성을 우선한다.
- 밸런싱 수치는 실제 플레이 데이터를 확보한 뒤 조정하며, 설계 문서에는 수치보다 효과의 방향과 제한 조건을 우선 기록한다.
